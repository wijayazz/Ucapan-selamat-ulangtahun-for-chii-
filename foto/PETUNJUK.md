# Foto kenangan

Masukkan enam foto ke folder ini dengan nama `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`, `5.jpg`, dan `6.jpg`.

Path foto diatur melalui array `FOTO` dalam `index.html`. Sesuaikan path jika menggunakan nama atau ekstensi berbeda. Huruf besar/kecil harus cocok.

Website tidak menyediakan upload foto. Jika foto belum tersedia, bingkai menampilkan simbol hati.

Ubah nama, ucapan, pesan, kesan, dan caption langsung di HTML. Buka `index.html` di browser untuk menjalankan website tanpa instalasi.

Alur klik: pembuka → enam foto → ucapan → pesan dan kesan → harapan.
